BUILT AROUND CONTROL

Security beyond ordinary app settings.

Jaguar adds protections at the operating-system level. These highlights describe intended functionality; detailed technical documentation and validation will follow.

01 / PHYSICAL ACCESS

Enhanced Lockdown Mode

Restrict USB data connections, prevent application installation and evict credential-encryption keys when entering lockdown.

02 / COMMUNICATIONS

SMS & USSD protection

Filter selected SMS categories, including Type-Zero messages, and require approval for third-party USSD requests.

03 / PRIVACY

System-wide privacy controls

Control clipboard access, screen capture and sharing; quickly clear the clipboard using a Quick Settings tile.

04 / INTEGRITY

System hardening

Additional kernel and partition protections, custom encryption parameters and device-specific bootloader options.

PROJECT PHILOSOPHY

Security with clear tradeoffs.

Jaguar is an independently developed Android 11-based ROM focused on user control and additional security mechanisms. Its features do not eliminate every risk, and Android 11's age and vendor firmware dependencies remain relevant to security decisions.

Future documentation will distinguish implemented behavior, tested guarantees and known limitations.
